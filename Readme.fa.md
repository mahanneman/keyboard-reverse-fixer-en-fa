## 🚀 نصب و اجرا

### روش ۱ – دانلود فایل اجرایی (توصیه شده)
- به صفحه‌ی [Releases](https://github.com/mahanneman/keyboard-reverse-fixer-en-fa/releases) بروید.
- نسخه‌ی مورد نظر را دانلود کنید:
  - `keyboard_reverse_fixer_en_fa_v1.exe` – نسخه‌ی پایه
  - `keyboard_reverse_fixer_en_fa_v2.exe` – نسخه‌ی هوشمند
- روی فایل `.exe` دوبار کلیک کنید – نیازی به پایتون یا کتابخانه‌ی اضافی نیست.

### روش ۲ – اجرا از کد منبع (برای توسعه‌دهندگان)
- مطمئن شوید پایتون ۳.۷+ نصب است.
- مخزن را کلون کنید:
  ```bash
  git clone https://github.com/mahanneman/keyboard-reverse-fixer-en-fa.git
  cd keyboard-reverse-fixer-en-fa
اسکریپت مورد نظر را اجرا کنید:

bash
# برای V1
python keyboard_reverse_fixer_en_fa_v1.py

# برای V2
python keyboard_reverse_fixer_en_fa_v2.py
🖱️ راهنمای استفاده – V2 (پیشنهادی)
برنامه را اجرا کنید.

متن انگلیسی‌نمای خود را در جعبه‌ی بالایی تایپ یا پیست کنید.
مثال: ;hgfdlk → منظور شما سلام بوده اما صفحه‌کلید روی انگلیسی بوده است.

تماشا کنید که ناحیه‌ی پایینی با تا ۵۰ نسخه‌ی تصحیح‌شده‌ی فارسی پر می‌شود – نتایج به‌صورت زنده ظاهر می‌شوند.

گزینه‌ی صحیح را پیدا کنید – معمولاً در بین چند گزینه‌ی اول قرار دارد (گزینه‌های پین‌شده در بالا می‌مانند).

آن را کپی کنید به یکی از روش‌های زیر:

کلیک چپ روی متن نتیجه.

کلیک روی دکمه‌ی 📋 کپی کنار نتیجه.

کلیک روی نتیجه و سپس فشار دادن Ctrl+C.

گزینه‌های پرکاربرد را پین کنید با کلیک روی دکمه‌ی 📌 – گزینه‌های پین‌شده همیشه در بالای لیست نمایش داده می‌شوند.

🖱️ راهنمای استفاده – V1 (پایه)
برنامه را اجرا کنید.

متن انگلیسی‌نمای خود را در جعبه‌ی بالایی تایپ یا پیست کنید.

روی دکمه‌ی "تبدیل / نمایش گزینه‌ها" کلیک کنید.

یکی از ۴ نسخه‌ی تصحیح‌شده را که در پایین نمایش داده می‌شوند انتخاب کنید.

روی هر نتیجه کلیک کنید (یا از دکمه‌ی کپی استفاده کنید) تا در کلیپ‌بورد کپی شود.
